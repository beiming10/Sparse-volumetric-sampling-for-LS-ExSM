# Initial code release

This release provides original experimental model inference, three pretrained checkpoints, small acquired examples, expected outputs and selected training implementations.

The full acquisition datasets, movie-grouped benchmark models and split manifests, oblique-simulation reproduction package, manuscript, reviewer correspondence, editable figure projects and historical experiments are outside this initial release. A complete paper-wide reproduction requires the corresponding additional data and experiment configurations.

Source coordinates preserve condition, acquisition identifiers and axial/frame indices while replacing workstation-specific drive paths with acquisition-relative paths. Model and image bytes are retained from the supplied reconstruction package.
